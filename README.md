A 100-word monologue for a fantasy villain who is secretly just very tired — Lord Veylan of the Ashen Spire, seven sieges into a war against Aldergate that stopped being a sprint a long time ago. His tiredness lives in the rhythm: short sentences, orders reversed mid-breath, cold porridge, a chair dented exactly in his shape. The program writes the monologue to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
